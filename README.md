# iec104-rtu

IEC 60870-5-104 远动终端（子站）实现：四遥采集、遥控「选择-执行」闭环、第三方主站互操作。

## 快速开始

```bash
# 需要 Python 3.8+，无第三方依赖
PYTHONPATH=src python scripts/run_slave.py --port 24040 --poll 2
```

然后用任意 IEC 60870-5-104 主站连接（TCP 2404/24040，公共地址 1），发起总召唤。
