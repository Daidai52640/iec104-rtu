# 继电器板实测记录（2026-10-21）

> 目的：把"从插上 USB 到 Modbus 写继电器"这一整段的过程与结论固化成可复核的证据。
> 全部为**真机实测**，不是手册推断。

---

## 一、环境

| 项 | 值 |
|---|---|
| 板子 | HKHZ 3U/2N 兼容板，4 入 4 出继电器，1 路 RS485 |
| 编程口 | 板载 USB → CH340 → Windows COM 口 |
| 编程软件 | GX Works2，机型 **FX3U(C)** |
| 转接 | USB-485（CH340，`VID_1A86&PID_7523`） |
| 供电 | 24V 2A |

---

## 二、踩过的坑（按发生顺序）

| # | 现象 | 根因 | 结论 |
|---|---|---|---|
| 1 | 插 USB 后设备管理器无新串口 | 板子需 24V 供电，USB 只是数据口 | 先上电，再看端口 |
| 2 | GX Works2 通信测试报 `ES:01802007` | 速度选了 9.6 Kbps | ⚠️ **必须 115.2 Kbps** |
| 3 | 485 发 Modbus 全无响应 | 接在 `485A1/B1` | ⚠️ **必须接 `485A0/B0`** |
| 4 | 写 `0x0500` 返回成功、回读也变，但**继电器不动** | 用了 FC03/FC06（保持寄存器 = 字软元件） | ⚠️ **Y 是位软元件 → 用线圈 FC01/FC05** |
| 5 | 试遍 50 组 波特率×校验×数据位 都无响应 | 不是参数问题，是通道接错 | 参数扫描无法替代"端子确认" |

---

## 三、最终确定的操作序列

### 3.1 编程（GX Works2）

```
连接目标：串行 RS-232C，COM<n>，115.2 Kbps，7-E-1
机型：FX3U(C)
```

梯形图（3 行）：

```
LD    M8002
MOV   H0071   D8120
MOV   K2      D8121
```

- `D8120 = H0071`：从站 + Modbus + 4800 + 8N1 + 1 路 485
- `D8121 = 2`：从站地址

写入后 **RUN 开关打到 RUN**（`M8002` 是上电初始脉冲，只在启动时执行）。

### 3.2 接线

```
USB-485 A  →  板子 485A0        ⚠️ 不是 A1
USB-485 B  →  板子 485B0
GND        →  板子 GND
```

### 3.3 Modbus 映射

| 用途 | 功能码 | 地址 |
|---|---|---|
| **Y 输出（继电器）** | **FC01 读 / FC05 写** | 线圈 **`0x0500 + n`** |
| **X 输入（DI）** | FC02 读离散输入 / FC04 读输入寄存器 | **`0x0400 + n`** |

## 四、闭环验证（原始帧）

```
读起始状态
  TX: 02 01 05 00 00 01 + CRC
  RX: 02 01 01 00 51 CC          → Y0 = 0

写 Y0 = ON
  TX: 02 05 05 00 FF 00 + CRC
  RX: 02 05 05 00 FF 00 8C C5    → 正常回显
  ★ 继电器吸合（人耳确认）

回读
  TX: 02 01 05 00 00 01 + CRC
  RX: 02 01 01 01 90 0C          → Y0 = 1

写 Y0 = OFF
  TX: 02 05 05 00 00 00 + CRC
  RX: 02 05 05 00 00 00 CD 35
  ★ 继电器松开（人耳确认）

回读
  RX: 02 01 01 00 51 CC          → Y0 = 0
```

**写入 → 动作 → 回读 → 释放，四步全部一致。**

## 五、地址探测结果（说明映射是怎么确定的）

| 功能码 | 0x0000 | 0x0100 | 0x0400 | 0x0500 | 其它 |
|---|---|---|---|---|---|
| FC01 读线圈 | 应答 | 应答 | 应答 | 应答 | 任意地址都应答（位区整体） |
| FC02 读离散输入 | 应答 | 应答 | 应答 | 应答 | 同上 |
| FC03 读保持寄存器 | 异常 02 | 异常 02 | 异常 02 | **应答** | 0x0580 起也应答 |
| FC04 读输入寄存器 | 异常 02 | 异常 02 | **应答** | 异常 02 | 仅 0x0400 |

⭐ 异常码 `02` = 非法数据地址。**"有异常应答"本身就证明从站在正常应答**——这是排查时的重要信号：**沉默 = 物理层没通；异常码 = 通了但地址不对**。

---

## 六、⚠️ 这次验证**没有**覆盖的

| 未覆盖 | 原因 |
|---|---|
| **独立回读** | 读 `0x0500` 是 Y 映像，与写入同路径；真正的独立回读要继电器辅助触点接 X0 后读 `0x0400` |
| 4 路输出的全部通道 | 只测了 Y0 |
| DI 输入 | X 侧没有接任何外部信号，读到的恒为 0 |
| 掉线检测 | 未做拔线测试 |
