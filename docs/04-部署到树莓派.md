## 1. 部署（从 Windows 开发机）

```powershell
cd F:\Project2
$tar = "$env:TEMP\p2-deploy.tar"
tar -cf $tar --exclude="__pycache__" --exclude=".pytest_cache" src scripts config tests README.md
scp $tar ddf@192.168.31.236:/tmp/p2-deploy.tar

ssh ddf@192.168.31.236 'rm -rf /home/ddf/iec104-rtu && mkdir -p /home/ddf/iec104-rtu && \
  tar -xf /tmp/p2-deploy.tar -C /home/ddf/iec104-rtu && rm -f /tmp/p2-deploy.tar'
```

⚠️ **用 tar 文件而不是管道**：PowerShell 管道会把二进制当字符串处理，压缩包会被写坏。

## 3. 两种运行模式

### 3.1 共存模式（P1 在跑时）—— 只读

```bash
cd /home/ddf/iec104-rtu
export PYTHONPATH=src
python3 scripts/run_slave.py --points config/points-pi.json --port 2404 --poll 2
```

- 数据源：`modbus_tcp` → 读 P1 的 `127.0.0.1:5020`（unit 1 = 真机变送器）
- **不碰串口**，P1 完全不受影响
- **不需要 pyserial**
- 能力：只读遥测（温湿度）

### 3.2 独占模式（P1 停时）—— 四遥全通

见文末「分时窗口」。

## 5. 收尾（务必做）

```bash
# 停 P2 —— ⚠️ 不要用 pkill -f run_slave.py，它会连带杀掉执行它的 shell
ps -eo pid,cmd | awk '/scripts\/run_slave\.py/ && !/awk/ {print $1}' | xargs -r kill

# 确认释放
ss -ltn | grep 2404 || echo "2404 已释放"

# 确认 P1 完好
systemctl is-active cems-device cems-gateway-plant1 cems-gateway-plant2
```

## 6. 分时窗口（独占模式）操作顺序

⚠️ **顺序不能反**：先停网关再停设备，否则网关会一直重连、把失败值写进 TDengine 污染 P1 的证据表。

```bash
# ① 停 P1
sudo systemctl stop cems-gateway-plant1 cems-gateway-plant2 cems-device
journalctl -u cems-device -n 3 -o cat          # 抄下停止时间点

# ② 把变送器 + 继电器板都挂到同一条 485 上（⚠️ 只接继电器板就没有遥测）

# ③ 起 P2（独占）
cd /home/ddf/iec104-rtu
export PYTHONPATH=src
python3 scripts/run_slave.py --points config/points-rtu.json --poll 2

# ④ 录证据：104 主站连 :2404，总召唤 + 遥控选择/执行

# ⑤ 恢复 P1
sudo systemctl start cems-device cems-gateway-plant1 cems-gateway-plant2
sleep 10
systemctl is-active cems-device cems-gateway-plant1 cems-gateway-plant2   # 期望 active ×3
journalctl -u cems-device -n 1 -o cat
```

### 必须在两边记录里写清的边界

> P1 与 P2 **不共享总线、不同时运行**。P1 的证据在 `<停止时间>` 前采集；
> P2 在 `<窗口起止>` 的独占窗口内采集（期间 P1 服务停止，TDengine 无该窗数据）。
> 硬件只有一根 USB-485，两项目分时复用。

## 7. ⚠️ 已知坑

| 坑 | 说明 |
|---|---|
| `pkill -f run_slave.py` 自杀 | ssh 命令行里也含这个字符串，会把自己的 shell 一起杀。用 `ps + awk + xargs kill` |
| 串口名会变 | Windows 上 COM3/COM4 会来回换；Pi 上一般回 `/dev/ttyUSB0`，但不要写死 |
| pyserial | 共存模式**不需要**；独占模式需要（`pip install pyserial`，装进独立 venv，别污染 P1 的） |
| 系统 python | Pi 的 `/home/ddf/cems/.venv` 是 P1 的，**不要往里装东西** |
